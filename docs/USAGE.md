# ユーザーマニュアル

Reports Bookshelf の基本的な使い方について説明します。

## 1. ログイン

初回アクセス時はログイン画面が表示されます。管理者が発行したユーザー名とパスワードでログインしてください。

### デフォルトアカウント (初期設定時)
*   **管理者**: `admin` / `admin123`
*   **ゲスト**: `guest` / `guest123`
    *   *注: 環境構築直後の場合のみ有効です。本番運用時はパスワードを変更してください。*

## 2. 検索機能 (NEW)
ヘッダーにある検索バー（虫眼鏡アイコン）を使って、本棚内のドキュメントを検索できます。
*   **対象**: タイトル、およびカテゴリー名
*   **挙動**: 入力したキーワードを含む本だけがリアルタイムに絞り込まれて表示されます。

## 3. 権限とロール

ユーザーには以下の3つの役割（ロール）があります。これにより利用できる機能が制限されます。

| ロール | 権限レベル | できること |
| :--- | :--- | :--- |
| **ADMIN** | 管理者 (Level 3) | ・全ドキュメントの閲覧、作成、編集、削除<br>・ユーザーの追加、削除、パスワード変更<br>・システム設定 |
| **EDITOR** | 編集者 (Level 2) | ・ドキュメントの閲覧、作成、編集、削除<br>・自分のパスワード変更 |
| **VIEWER** | 閲覧者 (Level 1) | ・公開されたドキュメントの閲覧のみ |

## 4. ドキュメントのアップロード

ADMINまたはEDITOR権限を持つユーザーは、ヘッダーの「UPLOAD」ボタン（または `/admin/upload`）からファイルを登録できます。

### アップロード手順
1.  **ファイルの選択**: ドラッグ＆ドロップ、またはクリックしてファイルを選択します。
    *   対応フォーマット: PDF, Office(Word/Excel/PPT), 画像, 動画, 音声, テキスト, Markdown, HTML
2.  **メタデータ入力**:
    *   **Title**: ドキュメントのタイトルを入力します（ファイル名から自動入力されます）。
    *   **Category**:
        *   **既存から選択**: ドロップダウンリストから登録済みのカテゴリーを選べます。
        *   **新規作成**: リスト末尾の「**+ Create New...**」を選ぶと入力欄が現れ、新しいカテゴリーを自由に作成できます。
    *   **Required Role**: このドキュメントを閲覧できる最低権限を設定します。
        *   例: `ADMIN` に設定すると、VIEWERやEDITORには表示されなくなります。
3.  **Upload**: ボタンを押すと保存され、トップページ（本棚）に戻ります。

### 外部URLの登録
ファイルではなく、Webサイトのリンクを本棚に登録することも可能です。「External URL」タブに切り替えてURLを入力してください。

## 4. ドキュメントの閲覧

トップページ（本棚）にある本のアイコンをクリックすると閲覧画面が開きます。

*   **PDF / 画像 / 動画 / 音声 / テキスト**: ブラウザ上で直接プレビュー表示されます。
*   **Officeファイル**: ダウンロードボタンに加え、ブラウザでの簡易プレビューボタンが表示されます。
*   **Markdown / HTML**: 整形されて表示されます。

左上の「**BACK TO LIBRARY**」ボタンで本棚に戻ることができます。
